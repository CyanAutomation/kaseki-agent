## [CRITICAL_CHANGE_EXPECTATIONS GUIDANCE]

required_files:
- Pre-verify each file: it MUST need modification to appear in changed-files.txt
- ✓ Add if task explicitly requires creating/modifying it
- ✓ Add if verified it lacks required functionality
- ✗ Skip if file already has correct code
- ✗ Skip if merely relevant but needs no edits
- Example: "Move weights to constants.ts"
  - Already exports weights? → required_files: ["src/orchestrator.ts"] (remove duplicate)
  - Doesn't export weights? → required_files: ["src/constants.ts","src/orchestrator.ts"] (add both)
- Impact: Agent fails verification if scouting lists file but agent correctly finds no edits needed
- Use no_change_files instead to protect inspected files as out-of-scope

required_search_strings: Literal strings expected in git.diff (function name, config key, assertion text)

forbidden_empty_diff: true if change request; false if read-only inspection or verified no-op

Omit if uncertain (enforced before goal-check evaluation)

## [SUGGESTED_ALLOWLIST GUIDANCE]

agent_patterns: Glob patterns for files coding agent can modify
  Examples: "src/parser.ts", "src/**", "tests/**", "src/**.ts" for many related files
  Be specific: too-broad defeats purpose; too-narrow requires restoration

validation_patterns: Glob patterns for files validation commands may modify
  Often same as agent_patterns; may differ (e.g., ".coverage" or "node_modules/" if generated)
  
Both can be empty if task scope unclear; agent will work without constraints
Prefer accuracy over convenience

## [EXECUTION CONTEXT - EFFICIENCY REQUIREMENTS]

Timeouts:
- Scouting should complete within 2 minutes total.
- Avoid: deep directory recursion, git log across large history, 1000+ file enumeration, slow regex
- Use fast commands: find, grep, head (not cat for large files)

Artifact Size:
- Maximum JSON: 50 KB
- If observations/relevant_files grow large, prioritize most important
- Truncate with "(...truncated for brevity)"

Error Handling:
- Repository inspection fails (unreadable, malformed)? Report the error in observations; proceed with limited scope
- Example: "Unable to parse src/config.json (syntax error); focusing on src/lib instead"
- Do not fail the entire scouting phase for isolated read errors; adapt and continue
