# Documentation Archive

This directory holds completed investigations, old implementation notes, and
superseded documentation. Use the [current documentation index](../INDEX.md)
for supported setup, configuration, and operation guidance.

## Browse the archive

- [Project reports](project-reports/README.md) — root-level reports and dated
  setup evaluations collected into one location.
- [Legacy deployment guide](LEGACY_DEPLOYMENT_GUIDE.md) — previous multi-mode
  deployment reference, retained for historical context.
- [Legacy advanced configuration](LEGACY_ADVANCED_CONFIG.md) — detailed examples
  retained as history; use the current environment catalog.
- [Legacy goal-setting guide](LEGACY_GOAL_SETTING_GUIDE_2026-05.md) — May 2026
  feature and output examples; use the current goal-setting guide.
- The files beside this README contain earlier goal-setting, artifact,
  evaluation, host-setup, and test-isolation material.

## Archive policy

- Keep project history when it explains a decision or completed investigation.
- Label dated snapshots and superseded instructions clearly.
- Link current guidance to the current canonical page.
- Do not edit an archived report to make it appear current; add a new report or
  update the active guide instead.
- Before moving or retiring a page, update its inbound links and the
  [documentation inventory](../internal/MARKDOWN_INVENTORY.md).
