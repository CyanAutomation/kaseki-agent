# Senku Decision Caller Inventory

Every active remote JEV decision call now goes through `src/decision-service/senku-client.ts` and the fixed authenticated `POST /v1/decisions` endpoint. No caller selects a provider, model, or destination URL. Each request is a single attempt. The Kaseki machine token is read from the configured secret file or local fallback path; a missing token prevents a request.

| Caller | Purpose and request | Result consumed | Time budget | Retry and failure behavior | Previous transport and Senku mapping |
| --- | --- | --- | --- | --- | --- |
| Task Admission (`src/task-admission.ts`) | After deterministic local credential screening, sends redacted task and repository fields with typed safety, risk, task-type, and validation-focus questions. | Noul/choice answers, usage, and advisory routing hints. | `KASEKI_TASK_ADMISSION_TIMEOUT_MS`, default 5 seconds. | One attempt. Missing credentials, network/timeout, or invalid response returns `degraded` and fail-open; deterministic local credential matches still reject. No remote error text is returned. | Previously used `DecisionService` backed by direct JEV/OpenRouter. Uses `DecisionService` backed by Senku. |
| Goal Check (`src/jev-workflow-evaluator.ts`) | Sends bounded run evidence and typed success-criterion questions; deterministic goal-contract validation runs first. | Noul criterion probabilities, optional applicability choices, outcome, and telemetry. | `KASEKI_GOAL_CHECK_DECISION_TIMEOUT_MS`, default 15 seconds. | One attempt per evaluation. Invalid contracts remain unmet before inference. Senku errors are recorded as unavailable and propagate to the existing evaluator failure path; no successful verdict is manufactured. The separate Pi evaluator is used only when explicitly selected by existing configuration, not as outage failover. | Previously used `DecisionService` backed by direct JEV/OpenRouter. Uses the same Senku-backed `DecisionService`. |
| Run Evaluation (`src/jev-workflow-evaluator.ts`) | Sends bounded metadata, goal/scouting context, validation evidence, and diff state with quality, confidence, completion, and optional failure-diagnosis questions. | Assessment, reviewer confidence, completion score, diagnosis, usage, and telemetry. | `KASEKI_RUN_EVALUATION_DECISION_TIMEOUT_MS`, default 15 seconds. | One attempt per evaluation. Failure is recorded as unavailable and propagates to the established run-evaluation failure path. Missing choice/score confidence maps to unknown or the conservative low score. | Previously used `DecisionService` backed by direct JEV/OpenRouter. Uses the same Senku-backed `DecisionService`. |
| Validation Recovery (`src/jev-workflow-evaluator.ts`) | Sends the failed command, exit code, and bounded redacted output with cause and recovery-action questions. | Advisory retry recommendation and confidence. | `KASEKI_VALIDATION_RECOVERY_DECISION_TIMEOUT_MS`, default 15 seconds. | One attempt. Service failure writes `status: unavailable` and `reason: classification_unavailable`; it never authorizes a retry. Existing observe/auto mode, exact command allowlist, transient-cause checks, confidence threshold, and one-retry ceiling remain authoritative. | Previously used `DecisionService` backed by direct JEV/OpenRouter. Uses the same Senku-backed `DecisionService`. |
| Caveman tool-output routing (`.pi-extensions.js`, `src/caveman/tool-output-router.ts`) | Sends bounded output metadata and a redacted goal summary. It does not send raw tool output or shell command text. | High-confidence local route choice or preserve/condense/discard choice; Caveman performs only its existing deterministic transform. | `KASEKI_CAVEMAN_ROUTER_TIMEOUT_MS`, default 1,200 ms. | One attempt. Missing token skips registration after the coding gateway is registered. Timeout, error, invalid response, null/low confidence, or protected evidence preserves the original output and does not block Pi initialization. | Previously dynamically imported `classifyWithJev()` and called the direct provider. The compatibility shim now calls Senku; the existing short timeout is retained. |
| Scouting/context handoff (`scripts/context-handoff.js`) | Sends a compact goal and bounded redacted scouting facts; required/protected and overflow facts bypass classification. | Preserve/condense/discard decisions and aggregate routing metrics. | `KASEKI_CAVEMAN_ROUTER_TIMEOUT_MS`, default 1,200 ms. | One attempt per handoff decision. Failure or uncertainty preserves the original required and protected facts; handoff construction continues. | Previously dynamically imported `classifyWithJev()` and called the direct provider. The compatibility shim now calls Senku. |
| API gateway Evaluation smoke check (`src/kaseki-api-gateway-smoke.ts`) | On explicit `?evaluation=true`, sends a fixed synthetic evaluation scenario with typed questions. | Answer validation, output-token usage, timing, and safe status/remediation. | 15 seconds. | One attempt. The probe is skipped unless requested; missing credentials skip it; Senku errors return safe diagnostics. Routine readiness checks do not incur inference. | Previously called the direct classifier. Now calls the same Senku-backed `DecisionService`. |

Pi coding inference continues through the existing LLM Gateway. It is separate from JEV decisions and is not used as an automatic fallback when Senku is unavailable. The optional Pi-based evaluation stages remain an explicitly configured workflow choice.
